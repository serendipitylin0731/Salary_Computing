# 教师坐班工资统计

这是一个基于 Tkinter 的本地桌面工具，用于批量导入班级坐班统计表、检查数据并生成教师津贴统计表。

## 运行

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 生成 Windows 可执行文件

直接双击 `build_exe.bat` 即可一键测试、清理旧产物并重新打包；也可以在 PowerShell 中运行：

```powershell
.\build_exe.ps1
```

脚本会在缺少依赖时自动安装，并在成功后删除中间构建文件。生成结果位于 `dist/SalaryComputing/`，其中不会包含 `example/` 或 `docs/module.xlsx`；收件人首次启动时需要自行选择模板。请整体保留并分发该文件夹，不要只复制其中的 `SalaryComputing.exe`，因为 `_internal/` 是程序必需的运行组件。

发布目录中的 `README.md` 来自 `USER_GUIDE.md`，只包含最终用户需要的操作说明，不包含开发和打包内容。

## 生成 Windows 安装包

安装 Inno Setup 6 后，双击 `build_installer.bat`，或运行：

```powershell
.\build_installer.ps1
```

脚本会先重新测试和打包程序，然后生成 `dist/SalaryComputing-Setup.exe`。安装位置默认为当前用户的本地应用目录，无需管理员权限，且保证程序可以保存工资配置和用户选择的模板。

## 使用流程

首次启动时，如果 `docs/module.xlsx` 不存在，程序会先显示主窗口和“缺少工资模板”提示；点击“立即选择模板”后才会打开文件选择窗口。程序会校验所选 `.xlsx` 文件，并将其复制、重命名为 `docs/module.xlsx`。进入程序后也可以通过顶部的“更换模板”按钮重新选择模板。

1. 选择包含所有班级统计表的文件夹。班级表支持“周六日监考”列；同一文件夹可放入 `周六日_节假日上课节数统计.xlsx`，列名为“序号、姓名、周六日上课、节假日补课”。程序会根据各班实际合计，分别取晚自修、中午、下午和周六日监考出现次数最多的总节数作为默认核对值。年级统计表作为独立文件预览和修改，不参与班级合计核验；未提供时按 0 处理。
2. 选择年级；自动生成的核对总节数仍可手动调整。
3. 查看导入结果。问题单元格会标红；姓名不匹配时会给出模板姓名推荐及相似度，可一键替换，也可将新人员追加到模板末尾。同一错误姓名出现在多个文件时，程序会询问是否批量替换。
4. 点击“校验并生成预览”。所有文件通过校验后会显示工资表。
5. 确认预览后点击“导出 Excel…”选择保存位置。表格支持滚轮上下滚动，按住 `Shift` 再滚动可左右移动。

生成时，各班“周六日监考”会按姓名累加，再加上年级统计表的“周六日上课”节数，按默认 100 元/节写入结果的“周六日”列；“节假日补课”按默认 150 元/节写入“节假日”列。两项都计入合计金额。

程序启动时会启用 Windows 每显示器高 DPI 感知，使主界面、提示窗口以及文件和文件夹选择窗口在系统缩放下保持清晰。修改显示缩放或移动到另一台显示器后若未立即刷新，重新启动程序即可。

工资标准保存在 `salary.json`。通过界面修改后，程序会同步更新 `docs/module.xlsx` 的金额列表头。班级表编辑会先可靠地保存到 `__cntcache__` 的本次会话目录，再尝试同步回原导入路径；带只读属性的文件会在写回时临时解除只读并在完成后恢复，若文件正被 Excel 占用或目录确实无写入权限，则静默跳过且不影响缓存修改。生成结果也暂存在本次会话缓存中，关闭程序时自动清理。
